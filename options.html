Colab Notebook
HLS Downloader hls-colab.ipynb
Downloads HLS streams and saves them as MP4 to Google Drive. Handles TikTok CDN segments (PNG-wrapped MPEG-TS), parallel downloading with retry, and ffmpeg muxing.
  1. Browse to the movie page — extension auto-detects and resolves all segment URLs.
  2. Open the panel → wait for N segments ready → click Save JSON.
  3. Download the notebook below and open it in Google Colab.
  4. Run Cell 1 (setup) → Cell 2 → Load JSON → select the file from step 2.
  5. Click Apply → run Cells 3 and 4. MP4 files saved to MyDrive/Movies/.
