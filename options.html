HLS Downloader downloader.ipynb

Downloads HLS streams detected by this extension and saves them as MP4 to your Google Drive. Handles TikTok CDN segments (PNG-wrapped MPEG-TS), parallel downloading, ffmpeg muxing, and retry on failure.

  1. Browse to the movie page. The extension detects the stream and resolves all segment URLs.
  2. Open the panel (click toolbar icon) → click Save JSON to download the stream data file.
  3. Download the notebook below and open it in Google Colab.
  4. Run Cell 1 (setup) → Cell 2 → click ⬆ Load JSON and select the file from step 2.
  5. Click ✓ Apply → run Cells 3 & 4. Files saved to MyDrive/Movies/.

About

Detects HLS streams (.m3u8) via network interception and XHR/fetch hooks. Resolves master playlists to segment URLs from the service worker (using your IP, bypassing IP-locked tokens). Exports cookies, page metadata, and full segment lists.
